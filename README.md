# talks
This is the repo for talks given by the HarvardSys lab members. 

### Repo structure
`template.potx` and `harvard-systems-group-template.potx` are PowerPoint templates.

`marp-template/` has a Marp (Markdown) version of the template. See `marp-template/README.md`.

`slides` folder stores all slides, please name your talk using `year-venue-name`.
