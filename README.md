# talks
This is the repo for talks given by the HarvardSys lab members. 

### Repo structure
`template.potx` (MaDSys Lab; the Marp version is based on this) and `harvard-systems-group-template.potx` (Harvard Systems Group) are PowerPoint templates.

`marp-template/` has a Marp (Markdown) version of the template, right now it only has the MaDSys Lab template (`template.potx`). See `marp-template/README.md`.

`slides` folder stores all slides, please name your talk using `year-venue-name`.
